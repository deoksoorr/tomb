## P0 — 맵·컨셉 개편 (사용자 지시: 가장 먼저)
- [ ] 0. **맵 개편 배포 전에 먼저**: 자동 업데이트 — 새 버전이 나왔고 사용자가 일정 시간(예: 3분) 입력이 없거나 탭이 숨겨져 있으면 채널을 유지한 채 자동 새로고침. 맵·프로토콜이 바뀌는 패치는 최소 클라이언트 버전을 올려 옛 화면을 강제 새로고침(실시간 서버가 welcome에서 버전 확인). 밤새 켜 둔 사용자가 아침에 새 맵을 보게. 실시간 서버 배포는 새벽 시간대에.
  - 접속 유지 검증: 새로고침(업데이트) 시 브라우저가 1001로 닫혀 20초 유예로 같은 자리·의자 복귀하는지 2브라우저로 확인, 클라이언트가 unload 때 1000으로 닫지 않게. 실시간 서버 배포(DO 재시작) 때도 자리 유지되게 — 접속자 위치·좌석·sid를 주기적으로(예: 변화 시 디바운스) storage에 스냅샷해 재시작 후 복귀를 resume으로 처리.
  - **현재 확인된 문제(11/11)**: 새로고침하면 클라이언트가 입구(SPAWN)에서 다시 시작해 `&x=..&y=..`에 입구 좌표를 보냄 → 서버 `relocate`가 좌석 반경 밖이라 좌석 해제·입구로 이동. 같은 sid·채널은 유지되지만(남들 눈엔 모닥불에서 입구로 순간이동) 앉은 자세·불멍 화면은 풀림. unload 때 1000으로 닫는 코드는 없음(브라우저 1001 → 20초 유예 정상).
    → 해결: 업데이트 새로고침 직전 sessionStorage에 {채널, 위치, 좌석 id, 상태(앉기·그네·불멍 화면), 방향} 저장 → 다시 열리면 그 위치에서 시작해 같은 좌표로 접속(서버가 좌석 유지) → 클라이언트가 같은 좌석에 다시 앉고 불멍 화면 복원. 저장값은 1분 지나면 무시. 일반 새로고침(F5)에도 같이 적용.
  - 안내 방식 2단계: (일반 패치) 화면 아래 **고정 배너**(닫기 없음) "새 버전이 나왔어요" + [지금 업데이트] → 누르면 채널 유지 새로고침, 3분 무조작이면 자동. (큰 패치=최소 버전 미달) 게임 위 **가리는 창** "새 버전으로 바꿔야 계속 놀 수 있어요" + [업데이트] + 10초 카운트다운 자동 새로고침, 실시간 연결은 서버가 거절(조작 중이어도 적용, 단 사냥 한 판·묘비 작성 폼은 끝날 때까지 대기).
