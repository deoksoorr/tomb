# 곤충잡기 화면 전면 개편 (A안: 위에서 내려다본 들판 한 장)

## 목표
다른 화면(스킬 효과·사냥터)에 비해 촌스러워진 곤충잡기(마을 수풀 곤충 채집, BugsScene meadow 테마)를 화면·연출·소리·점수판까지 새로 만든다.

## 바꾸지 않는 것
- 규칙: 덤불 9곳, `bugsPlan` 출현 계획, `BUG_SCORE`·`comboMult`, 키(Q W E / A S D / Z X C)·누르기·탭
- 서버 점수 검증·보상·결과 형식(`BugsResult`)

## 화면
- 들판 한 장: 마을과 같은 내려다보는 시점. 땅 결·꽃·돌·작은 웅덩이·바람에 살랑이는 풀
- 덤불 9개: 3줄, 줄마다 엇갈림, 모양·크기 조금씩 다르게(바둑판 느낌 없음). 판정은 덤불 둘레를 넉넉히
- 키 표시: 덤불 앞 작은 나무 팻말. 터치 화면에서는 숨긴다
- 시간대(한국 시각): 낮 = 맑은 들판·나비, 노을 = 주황빛·잠자리, 밤 = 어두운 들판·반딧불이

## 곤충
- 날아 들어와 덤불에 내려앉는다(출현 시각부터 바로 잡을 수 있음 — 규칙 그대로), 머무는 동안 날개 접었다 폈다, 놓치면 날아간다
- 더 크고 자세한 그림. 황금 곤충은 반짝이 꼬리, 꿀벌은 붕붕 떨기, 낙엽은 팔랑이며 내려온다

## 손맛
- 잡기: 잠자리채가 덤불을 덮치고 그물에 담기는 짧은 연출. 헛치기: 채가 허공을 휘젓는다
- 콤보 단계별로 꽃잎·빛 가루가 커지고 가장자리가 살짝 밝아짐, 큰 콤보에 짧은 글자
- 소리: 곤충·콤보 단계별로 다르게, 공용 소리 장치(lib/sharedAudio) 사용

## 점수판·시작·결과
- 나무 팻말 느낌 점수판: 남은 시간 막대·점수·콤보
- 시작 "준비 → 시작!", 끝 결과 카드(잡은 수·황금·최고 콤보·점수)

## 확인
- 기존 테스트 통과 + 새 순수 함수 테스트, 1280×800·390×844 스크린샷(낮·노을·밤)
