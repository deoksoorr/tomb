# 구글 계정 연결·로그인

## 결정 (사용자)
- 소셜 로그인은 구글만
- 기존 계정은 [포인트] → 계정 정보에서 구글을 연결하고, 그다음부터 구글로 로그인

## 흐름
- 계정 정보: [구글 계정 연결] → 구글 동의 화면 → 돌아오면 "연결됨" · [연결 끊기]. 구글 계정 하나 ↔ 게임 계정 하나 (이미 다른 계정에 연결된 구글이면 거절 안내)
- 입구 화면: 기존 [코드로 들어가기] 옆에 [구글로 들어가기]. 연결된 계정이면 그 계정으로 입장, 아니면 "연결된 계정이 없어요 — 새로 시작하거나 코드로 들어간 뒤 계정 정보에서 연결해 주세요" + [새로 시작하며 구글 연결] 선택지
- 코드 로그인은 그대로 (구글은 추가 수단). 계정 코드 재발급·제재·휴면 이름 규칙 그대로

## 개인정보 최소
- 구글에서 받는 것: 고유 번호(sub)만 (scope openid). 이메일·이름·사진은 받지 않음
- 저장: sub를 서버 비밀값으로 해시한 값 ↔ 계정 id. 원래 sub도 저장하지 않음
- 개인정보 처리방침·자주 묻는 질문 갱신

## 보안
- 인가 코드 흐름 + PKCE + state(서명된 짧은 쿠키), id_token 서명·aud·iss·exp 검증
- 돌아오는 주소는 운영·테스트 서버 각각 고정 (열린 리디렉트 없음)
- 차단된 계정·기기는 구글로도 입장 불가

## 운영 준비 (사용자 몫)
- 구글 클라우드 콘솔에서 OAuth 클라이언트(웹) 만들기, 승인된 리디렉션 주소 2개(운영·테스트)
- Vercel 환경 변수 GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET (운영·테스트 서버 각각)
- 설정이 없으면 구글 단추는 숨김 (지금처럼 코드만)
