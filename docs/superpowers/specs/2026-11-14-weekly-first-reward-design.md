# 주간 랭킹 1위 보상

## 대상 (3개)
- 포인트(이번 주 모은 포인트), 사냥 처치(이번 주 처치 수), 낚시(이번 주 가장 큰 물고기 — 전체 물고기 판)
- 제외: 하우징(최종 콘텐츠), 사냥터별 최고 기록(1위가 너무 많음), 꾸미기·사냥 레벨(누적)

## 보상
1. 랭킹별 1위 전용 꾸미기를 한 주 동안: 포인트 = 금화 왕관, 사냥 처치 = 붉은 깃털 투구 장식, 낚시 = 황금 물고기 모자. 상점에 안 나옴. 다음 주 1위가 정해질 때까지(같은 사람이 또 1위면 이어짐)
2. 아주 화려한 1위 전용 오라(몸 둘레 효과): 랭킹별 색·모양이 다르게 — 포인트 = 금빛 동전·빛줄기, 사냥 처치 = 붉은 불꽃·불티, 낚시 = 푸른 물결·물방울. 기존 꾸미기 효과(cosmeticFx)보다 한 단계 위로 눈에 띄게, 성능은 지키게
3. 이름 옆 작은 배지 "이번 주 포인트왕/사냥왕/낚시왕"
4. 포인트 소량(1,000P, 상징)
5. 명예의 전당: 랭킹 창에 역대 주간 1위 기록

## 규칙
- 매주 월요일 0시(KST) 마감, 자동 지급(한 번만 — 중복 지급 없게)
- 운영자 계정 제외, 동점이면 먼저 달성한 사람
- 지급 시 본인 알림 창 + 전체 공지 줄에 한 번

## 다관왕 (사용자 결정)
- 한 사람이 2~3개를 차지하면 다 준다(꾸미기·포인트 모두 개수만큼)
- 배지는 합쳐서 "이번 주 2관왕/3관왕"
- 오라는 겹쳐 그리지 않고 하나로: 2관왕은 차지한 두 랭킹 색이 섞인 오라, 3관왕은 세 색이 도는 무지개 오라(가장 화려하게)

## 주간 레이스 화면 (사용자 결정)
- 새 버튼 없이 기존 랭킹 창 맨 앞에 "이번 주 레이스" 칸
- 랭킹 3개마다 1~3등 시상대(캐릭터 모습), 마감까지 남은 시간, 내 순위·1위와 차이
- 창이 열려 있는 동안 30초마다 갱신
- 이번 주 1위가 바뀌면 마을 공지 줄에 "○○님이 이번 주 낚시 1위로 올라섰어요" (너무 잦지 않게 같은 랭킹은 몇 분에 한 번까지)
