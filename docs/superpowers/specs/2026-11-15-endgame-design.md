# 사냥 끝판: 초월 레벨 + 번아웃 단계 (2026-11-15)

## 배경
- 사냥 최고 레벨 50 (1→50 누적 EXP 약 17만). 오픈 1주 만에 50 달성자가 나왔다.
- 플레이어 다수가 게임 업계 7~10년차 이상 → 최적 루트를 바로 계산한다. **최대 효율로 해도 몇 달** 걸려야 한다.

## 원칙
1. 1~50 구간(EXP 곡선·능력치·기존 사냥터)은 그대로.
2. 끝판 보상은 포인트가 아니라 자랑거리(칭호·표시·랭킹). 포인트는 기존 사냥 한도(600) 그대로.
3. Redis 명령 추가는 최소 (판 끝 1회 저장에 얹고, 랭킹은 기록 갱신 때만 쓴다).
4. 서버 검증(판 결과 상한)은 기존 방식 유지 — 단계 배율을 상한 계산에도 반영.

## B. 초월 레벨 (★51 ~ ★100)
- 레벨 50 이후 얻는 EXP는 초월 EXP로 쌓인다. 초월 레벨 t = 1..50 (표시 ★51..★100).
- 초월 EXP는 **지옥 난이도(번아웃 단계 포함)에서만** 들어온다. 다른 난이도·미니게임 EXP는 50에서 버린다.
- 곡선: tExpToNext(t) = round(BASE × GROWTH^(t-1)). 기준값은 **최대 효율(하루 4시간, 시간당 판 수 한도까지)로 ★100까지 4개월 이상**, ★51은 하루 이내가 되게 맞춘다 (시작 제안: GROWTH 1.06, BASE는 지옥 판 EXP 실측으로 보정).
- 능력: 초월 5레벨마다 능력치 1포인트 (STAT_MAX 상한 그대로). 전투력은 거의 안 는다.
- 표시: 캐릭터 창·사냥 로비·랭킹 레벨 탭에 ★N. 레벨 랭킹 정렬 = 레벨 → 초월 레벨 → 초월 EXP.
- 칭호: ★60(은) ★75(금) ★90(금) ★100(전설).

## A. 번아웃 단계 (지옥 위 무한 단계)
- 레벨 50이면 지옥 사냥터 화면에 [번아웃 단계] 입장. 1단계부터.
- **바로 아래 단계를 한 번도 쓰러지지 않고 끝까지 깨야** 다음 단계가 열린다 (최고 연 단계 저장).
- 몬스터: 체력·공격력 × 1.3^단계 (복리), 방어 × 1.12^단계. 사냥터는 지옥 사냥터들을 단계마다 돌아가며.
- 저주 (누적):
  - 3단계~: 물약 금지
  - 6단계~: 받는 회복 절반
  - 9단계~: 제한 시간 −20%
  - 12단계~: 몬스터 이동 속도 +20%
  - 15단계~: 쓰러지면 그 자리에서 판 끝 (부활·버티기 없음)
  (엔진에 이미 있는 값만 조정하는 단순 배율이어야 한다 — 새 패턴을 만들지 않는다)
- 보상: 포인트는 지옥과 같음(사냥 한도 안). EXP = 지옥 EXP × (1 + 0.1 × 단계) → 초월 EXP로. 드롭은 지옥 표 그대로.
- 랭킹: 주간 "번아웃 최고 단계" (단계 → 깬 시간 짧은 순). 운영자 계정 제외. 기록 갱신 때만 쓴다.
- 칭호: 5단계(은) 10단계(금) 20단계(금) 30단계(전설).

## 검증
- 판 시작 티켓에 단계를 싣고, 서버는 단계 ≤ 최고 연 단계인지 확인.
- 판정 상한(처치 속도·웨이브 시간·제한 시간)에 단계 배율·저주를 반영.
- 단위 시험: 초월 곡선 합계·4개월 기준 계산, 단계 해금 규칙, 단계 배율, 판정 상한, 랭킹 정렬.
